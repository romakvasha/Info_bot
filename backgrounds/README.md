# Фони для картинок (необов'язково)

Без фонів картка має білий верх і червону смугу, як польський прапор.
Якщо хочеш фото, поклади сюди файли з назвами тем:

| Файл | Тема |
|---|---|
| `legalization.jpg` | Легалізація |
| `work.jpg` | Робота |
| `money.jpg` | Гроші й податки |
| `social.jpg` | Соцвиплати |
| `health.jpg` | Медицина |
| `education.jpg` | Освіта |
| `transport.jpg` | Транспорт і кордон |
| `safety.jpg` | Безпека |
| `politics.jpg` | Політика |
| `ukraine.jpg` | Україна і Польща |
| `life.jpg` | Життя в Польщі |

Підходять .jpg, .png і .webp, бажано горизонтальні (від 1280×530). Бот сам обріже
фото й затемнить його, а заголовок стане білим. Тем без фото це не стосується:
вони лишаються з білим верхом.
