# Новини Польща

Бот для Telegram-каналу, який сам знаходить свіжі новини про Польщу, відбирає
найважливіші для іноземців, переказує їх українською, малює картинку й публікує.
Працює на GitHub Actions за розкладом: комп'ютер для цього не потрібен.

## Як це працює

1. Бот читає RSS-стрічки польських медіа (список у `config.py`).
2. AI (Gemini або Claude) вибирає до двох найважливіших новин, яких ще не було в каналі.
3. Для кожної бот завантажує повний текст статті, і AI пише короткий пост своїми словами.
4. Бот малює картку із заголовком і публікує її з підписом та посиланням на джерело.
5. Список опублікованого зберігається в `data/posted.json`, щоб новини не повторювались.

## Встановлення

Перед цим мають бути готові канал, бот-адмін, ключ Gemini, приватний репозиторій
і три секрети: `TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY`, `TELEGRAM_CHANNEL`.

1. Розпакуй архів. У репозиторії на GitHub натисни **Add file → Upload files**,
   перетягни туди **весь вміст** розпакованої папки (разом із папками `.github`,
   `fonts`, `backgrounds`) і натисни **Commit changes**.
2. Перевір, що в репозиторії з'явився файл `.github/workflows/news.yml`. Якщо папки
   `.github` немає, створи файл вручну: **Add file → Create new file**, у полі назви
   введи `.github/workflows/news.yml`, встав вміст файлу з архіву й збережи.
3. Відкрий вкладку **Actions → Новини Польща → Run workflow**. Для першої перевірки
   можна поставити галочку «Тестовий запуск без публікації»: тоді бот лише покаже
   в лозі, що б він опублікував.
4. Запуск триває 1–3 хвилини. Зелена галочка означає, що все гаразд. Червоний хрестик —
   відкрий запуск і подивись лог кроку «Зібрати й опублікувати новини».

Далі бот працює сам: 4 рази на день публікує по 1–2 новини. Якщо запуск упаде,
GitHub надішле лист на пошту.

## Розклад

Розклад задається у файлі `.github/workflows/news.yml`, рядок `cron`. Час там у UTC:
у Польщі влітку це +2 години, взимку +1.

| Що хочеш | Рядок cron |
|---|---|
| 4 рази на день (зараз) | `"17 5,9,13,17 * * *"` |
| Щогодини з 7:00 до 21:00 (літо) | `"17 5-19 * * *"` |
| Двічі на день | `"17 6,16 * * *"` |

GitHub інколи запускає заплановані задачі із запізненням на 10–30 хвилин, це нормально.

## Налаштування

Усе основне лежить у `config.py`:

- `POSTS_PER_RUN` — скільки новин максимум за один запуск;
- `RSS_FEEDS` — джерела (назва й адреса RSS), можна додавати й видаляти;
- `TOPICS` — теми, емодзі й хештеги;
- `CHANNEL_TITLE` і `ADD_CHANNEL_LINK` — підпис на картинці й посилання на канал у постах.

Стиль постів і критерії відбору новин — у `prompts.py`, звичайним текстом.
Редагувати файли можна прямо на GitHub (іконка олівця).

## Картинки

Без додаткових файлів картка має білий верх із заголовком і червону смугу, як польський
прапор. Щоб використовувати фото, поклади в папку `backgrounds` файли з назвами тем
(`work.jpg`, `legalization.jpg` тощо). Подробиці — у `backgrounds/README.md`.

## Перехід на Claude

1. Створи ключ у Claude Console і додай секрет `ANTHROPIC_API_KEY`.
2. У `config.py` зміни рядок на `AI_PROVIDER = "claude"`.

## Тест на своєму комп'ютері

Потрібен Python 3.10 або новіший. У PowerShell:

```powershell
cd шлях\до\novyny-polshcha
python -m pip install -r requirements.txt
python card.py                      # приклади карток у папці preview/, ключі не потрібні
$env:GEMINI_API_KEY = "твій_ключ"
python main.py --dry-run            # повний прогін без публікації, результат у preview/
```

## Якщо щось не працює

| Повідомлення в лозі | Що зробити |
|---|---|
| `Не задано секрети…` | Перевір назви секретів у Settings → Secrets and variables → Actions |
| `Unauthorized` | Токен бота неправильний: створи новий у @BotFather через /token |
| `chat not found` | `TELEGRAM_CHANNEL` має бути адресою публічного каналу з @ |
| `not enough rights` або `not a member` | Додай бота адміністратором каналу з правом публікації |
| `API key not valid` | Перевір секрет `GEMINI_API_KEY` |
| `жодна модель Gemini не відповіла` | Тимчасовий збій або ліміт; наступний запуск зазвичай проходить |
| `джерело недоступне` | Одне джерело не відповіло, бот працює з рештою. Якщо так щодня, заміни його в `config.py` |

Файл `data/posted.json` — це пам'ять бота. Не видаляй його, інакше бот може
повторно опублікувати новини за останню добу.
